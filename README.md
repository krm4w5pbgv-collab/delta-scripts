# Delta Scripts — موقع فهرسة السكربتات

## المتطلبات
- Node.js إصدار 20 أو أحدث

## التشغيل على جهازك
1. فك ضغط المشروع.
2. افتح مجلد المشروع في Terminal.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
5. افتح `.env` وضع بيانات الأدمن التي اخترتها في:
   - `ADMIN_USERNAME`
   - `ADMIN_PASSWORD`
   - `ADMIN_PIN`
   - `SESSION_SECRET` (اكتب قيمة عشوائية طويلة لا تقل عن 32 حرفاً)
6. نفّذ: `npm start`
7. افتح `http://localhost:3000`

## قاعدة البيانات
- تحفظ السكربتات في `data/catalog.sqlite`.
- تحفظ جلسات تسجيل الدخول في قاعدة SQLite منفصلة داخل `data/`.
- احتفظ بمجلد `data/` عند نقل الموقع أو تحديثه.

## النشر على الإنترنت
ارفع المشروع إلى استضافة تدعم Node.js 20+، واضبط متغيرات البيئة الأربعة في لوحة الاستضافة. اجعل `NODE_ENV=production`، واستخدم قرصاً دائماً (persistent disk/volume) لمجلد `data/`؛ وإلا قد تُحذف قاعدة البيانات عند إعادة تشغيل بعض منصات الاستضافة. فعّل HTTPS دائماً.

## تنبيهات
- لا ترفع ملف `.env` إلى مستودع عام ولا ترسل بيانات الأدمن لأحد.
- لا توجد بيانات دخول افتراضية داخل ملفات المشروع.
- يقبل الموقع روابط HTTP وHTTPS فقط.
- الموقع يعرض روابط السكربتات التي يضيفها الأدمن؛ افحص الروابط قبل نشرها ولا تشغّل ملفات مجهولة.
