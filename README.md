# MOXB — النسخة الأولية

## المزايا
- دخول بأربع خانات: اسم المستخدم، كلمة المرور، كلمة الأصدقاء، رمز الدخول.
- إنشاء الحسابات وحذفها من لوحة الأونر فقط.
- تشفير الرسائل وفكها محلياً في المتصفح باستخدام AES-GCM واشتقاق مفتاح PBKDF2.
- صفحة مستقلة لإعداد شفرة قابلة للنسخ والإرسال.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. أنشئ قاعدة PostgreSQL.
3. انسخ `.env.example` إلى `.env` واملأ القيم.
4. نفّذ `npm install` ثم `npm start`.
5. افتح `http://localhost:3000`.

## النشر على Render
- ارفع محتويات المشروع إلى مستودع GitHub جديد.
- أنشئ PostgreSQL من Render وانسخ Internal Database URL إلى `DATABASE_URL`.
- أنشئ Web Service من المستودع، Build Command: `npm install`، Start Command: `npm start`.
- أضف متغيرات البيئة المذكورة في `.env.example` إلى إعدادات الخدمة.
- أنشئ قيمة عشوائية طويلة لـ `SESSION_SECRET`.
- تأكد من استخدام قاعدة بيانات دائمة وعدم مشاركة متغيرات البيئة.

## ملاحظات مهمة قبل الاستخدام الفعلي
- هذه نسخة تأسيسية وليست مراجعة أمنية نهائية.
- لا تشارك كلمات المرور أو كلمات الأصدقاء أو رموز الدخول في المحادثات.
- كلمة الأصدقاء لا تُحفظ كنص صريح؛ تُستخدم نسخة مشتقة للتحقق. عند التشفير، يكتب الطرفان الكلمة المشتركة مرة أخرى.
- احتفظ بنسخة احتياطية من قاعدة البيانات. أضف حدود محاولات الدخول ومراجعة أمنية قبل وضع بيانات حساسة.
